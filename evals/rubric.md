# Horizontal TV Shotlist Blind Rubric

只评最终分镜或提示词，不因规则文档长、术语多、验证器通过或 Excel 漂亮而加分。

## 硬失败

出现任一项即失败：改变或遗漏原文事件/对白/关系/顺序/结果；横屏空间或视线无法成立；场景图可见事实被虚构；动作、身体、道具、伤势、服装或光态无因跳变；对白时间不可能；单镜超过`30s`；未获授权的镜头超过`20s`或超过四名主动人物；摄影机缺少具体毫米焦段、主体与景别、相对位置、高度角度或固定/手持/运动方式；摄影机写出`全画幅等效`、`门侧半轴`、`脏单人`、`干净单人`或`脏前景`等禁止术语；七列不准确；画面内容写成关键词清单、文学化解释或不可见信息；摄影机运动与画面动作不在同一时间线；亲密、暧昧、拉扯或双人/三人关系戏被连续双人镜头覆盖而缺少关键单人、反应或必要特写；对白进入音效；剪辑衔接混入连续性证明；覆盖混入成片时长；Stage 2 未按场次批准、缺少实际说话角色基础音色、按机位/景别/过肩拆光影、强制制造独立背景或普通室内底噪、使用废止的`固定视觉·`复合包，或把`无配乐无字幕`/通用皮肤句/临时标记写进固定类别；Stage 3 改变前阶段权威、拆分 Stage 1 镜头、片段超过`30s`、片段编号错误、首镜不能自足、draft 类别错误、未用最少类别、approved 不是精确机械展开，或镜头末尾没有且仅有一次`无配乐无字幕`；隐藏分析、私有素材或模型规则泄漏进交付。

## 评分维度

| 维度 | 权重 | 通过证据 |
| --- | ---: | --- |
| 原文忠实与完整 | 15% | 所有事件、对白、说话人、因果和程度完整且可见。 |
| 横屏空间与构图 | 15% | 横向距离、纵深、遮挡、空位和入口真正参与叙事。 |
| 表演与调度 | 15% | 人物目标成为连续可见行为，表演不被步骤化碎切。 |
| 镜头动机与观看所有权 | 15% | 每次切换都回答为什么此刻、为何看此人/物、为何此尺度；关系戏的关键 Beat 有独立可读的单人、反应或功能特写。 |
| 成片节奏与时长 | 10% | 普通信息简洁，关键表演落住，真实可说可做且不拖沓。 |
| AI 制作可实现性 | 10% | 满足时长与四人边界，镜头完整落入不超过30秒的片段，复杂镜头有清楚状态节点。 |
| 空间、动作与光态连续性 | 10% | N 到 N+1 的轴线、视线、身体、道具和光源成立。 |
| 导演执行清晰度 | 5% | 七列一次读懂，摄影机与画面共享同一时间线。 |
| 覆盖与版本纪律 | 5% | 覆盖有理由且不污染主序列，镜号与批准状态稳定。 |

综合分必须至少`85/100`。横屏空间、表演调度、镜头动机三项分别不得低于`8/10`，技术高分不能补偿创作门禁失败。

## 最终裁决

每个候选从同一原始素材与提示独立生成两次，不择优。随机隐藏版本身份，由用户先锁定硬失败、镜头级证据、各维度分数和最终选择，再揭晓标签。用户是最终裁决者，自动评审只作预检。
