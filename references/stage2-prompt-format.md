# Stage 2 极简固定提示词格式

卡片正文必须可以原文机械展开。只写固定条件，不写镜号、适用镜号、Stage 1 内容、当前表演、`无配乐无字幕`或临时负面限制。

## 基础音色

```markdown
### 基础音色·角色名

音色：年龄与性别声线，口音；音域与共鸣；声音厚薄、清晰度与稳定质地。稳定听感是……
```

`稳定听感`最多一句，不展开人物小传或场次表演。后续场次完整展示并逐字复用项目已批准原文。

## 可选场次或阶段音色

```markdown
### 阶段音色·角色名·简短状态

音色状态：连续阶段中稳定存在的音量、气息、语速、咬字或发声媒介变化。
```

只在状态连续覆盖多个镜头时建立。

## 人物光影

```markdown
### 光影·角色名

光影：主光源为……，位于……，约……K，照亮角色……侧脸颊、颈肩与身体，形成……lux的主要亮面；另一侧自然落入阴影，保持……lux的柔暗部。人物背后为……，背景约……lux。整体低照度/目标曝光、目标反差、目标色调与真实电影质感。
```

## 多人光影

```markdown
### 光影·角色A与角色B

光影：逻辑主光为……，位于……，约……K。角色A的……侧形成……lux亮面，另一侧保持……lux暗部；角色B的……侧形成……lux亮面，另一侧保持……lux暗部。人物背后为……，背景约……lux。整体……
```

三至四人卡只增加真实重复出现的主要人物，不自动穷举组合。稳定光态必须给 K、亮面 lux、暗面 lux 和背景 lux；动态光态另写闪动颜色、方向、规律、作用区域与曝光结果，不强求动态峰值。

## 极少数独立背景

```markdown
### 背景·区域或方向

背景：必要空间锚点、纵深关系和背景曝光，约……lux。
```

## 可选环境、群演与场次声音

```markdown
### 环境·简短状态

环境：持续可见并直接影响受光、遮挡、动线、构图或物理连续性的环境状态。

### 群演·简短状态

群演：持续围观对象、聚集方式、错峰反应、秩序，以及对主体遮挡、动线或受光的影响。

### 场次声音·简短声源

声音：成片中清楚可闻、持续覆盖大部分场次或多个连续镜头，并具有空间或剧情作用的声音。
```

不输出空卡片，不使用`固定视觉·`，不把多个类别合并成复合包。
