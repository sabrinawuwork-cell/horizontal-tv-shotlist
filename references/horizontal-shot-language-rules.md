# 横屏剧集 Shot Designer Agent 完整镜头规则库

> 本文件保留完整规则编号，并融合用户后续明确批准的修订；它是当前权威规则库，不是历史原文存档。正式工作顺序为：剧情事实与人物关系 → 场次目标 → 戏剧 Beat → 空间布局 → 主轴线 → 人物 Blocking → 主镜头设计 → 必要覆盖镜头 → 信息与反应镜头 → 剪辑节奏 → 连续性复核。“主镜头设计”指预期成片主序列，不强制 Master Shot。后续批准规则与较早文字冲突时，以后续批准规则为准，并直接清除旧冲突，不并列保留两套执行口径。

## 一、Agent总执行逻辑

Agent生成分镜时，应按照以下顺序决策：

**剧情事实与人物关系 → 当前戏剧Beat → 空间结构与轴线 → Blocking人物调度 → 主镜头设计 → 必要覆盖镜头 → 信息与反应镜头 → 剪辑节奏 → 连续性检查。**

发生规则冲突时，优先级如下：

1. 不改变剧情、人物关系、事件顺序和关键信息。
2. 保证空间、轴线、视线、动作方向和道具方向正确。
3. 准确表达当前Beat中的信息、情绪和权力变化。
4. 保证镜头可执行、可剪辑，避免一个镜头承担互相冲突的任务。
5. 最后才考虑风格化、复杂运镜和视觉奇观。

横屏分镜不采用固定的“运动镜头比例”。固定或运动必须由剧情决定，禁止为了达到数量比例而给所有镜头机械添加缓推、横移或环绕。

# 第一部分：镜头语言规则

## A. 镜头功能、景别、角度、焦段、景深与运镜

| ID | 规则 | 功能与限制 |
|---|---|---|
| ML01 | 每个镜头必须先确定主要叙事功能，再决定景别和运镜。 | 功能可以是建立空间、交代动作、表现反应、释放信息、强化关系或完成转场，不能先选“好看的镜头”再寻找理由。 |
| ML02 | 一个镜头原则上只设置一个主要功能，可以同时承载一至两个次要功能。 | 避免在短时间内既建立空间、又交代道具、又展示多人反应、又完成复杂动作，造成主体不明。 |
| ML03 | 镜头主体必须具有明确的视觉优先级。 | Agent应在内部明确第一主体、第二主体和背景信息，成稿以可见构图与具体反应者落实，不输出分析标签，也不能只写“画面中所有人发生反应”。 |
| ML04 | 超大全景用于建立世界规模、地理环境、阵营规模或人物的极端渺小。 | 只有环境本身具有剧情意义时使用，不用作无功能的风景展示。 |
| ML05 | 大全景应交代主要人物、入口、出口、危险来源及空间方向。 | 横屏建立镜头不是漂亮空景，必须为后续调度和剪辑建立地图。 |
| ML06 | 全景优先用于完整身体动作、多人调度、打斗起势和人物进出空间。 | 涉及摔倒、追赶、身体距离变化时，应先保证动作完整可见。 |
| ML07 | 中全景适合同时保留人物身体语言、关系距离和部分环境。 | 可作为横屏人物戏的常用主镜头，尤其适合走位对白和权力关系变化。 |
| ML08 | 中景是信息、表演与空间之间的默认平衡景别。 | 普通对白、任务交代和关系稳定阶段优先使用，不必一开始就进入近景。 |
| ML09 | 中近景用于情绪开始收紧、语言变得私人或人物进入心理防御状态。 | 应在剧情强度提高时使用，不能全场从头到尾保持相同中近景。 |
| ML10 | 近景用于明确心理转折、关键反应和无法由身体动作充分表达的情绪。 | 近景应对应Beat，而不是谁说话就自动切谁的近景。 |
| ML11 | 大近景只用于高强度心理压力、失控边缘或极私密时刻。 | 连续使用会削弱空间关系，并使后续缺少更强的景别升级手段。 |
| ML12 | 极特写只用于剧情必须识别的微小信息。 | 例如瞳孔变化、扳机、伤口、手机文字、戒指、钥匙，不应用于无意义的眼睛或嘴唇装饰镜头。 |
| ML13 | 插入镜头必须交代会改变人物判断或剧情结果的信息。 | 道具只是被拿起但没有剧情作用时，不必单独插入特写。 |
| ML14 | 切出镜头用于补充环境反应、旁观者、危险源或时间信息。 | 切出镜头应帮助主场景，而不是为了掩盖缺乏镜头设计而随意插入。 |
| ML15 | 双人镜头优先用于表现关系整体，而不是单独放大某一方。 | 两人的距离、朝向、站坐高差和画面占比应体现当前关系。 |
| ML16 | 三人及多人镜头必须形成清楚的阵营、层级或三角关系。 | 避免所有人物横排站立；应通过前后景、左右分组和高度形成关系。 |
| ML17 | 过肩镜头用于保持对手存在感和空间方向。 | 前景肩膀大小应与关系相关，压迫者的肩膀可以更重，弱势人物的遮挡不应无理由过大。 |
| ML18 | 单人镜头若通过对方肩膀建立关系，直接写明过谁的左/右肩拍谁；若是其他虚化前景，直接点名前景人物或物体。 | 前景必须具有对峙、试探、暧昧、压迫或信息遮挡功能。 |
| ML19 | 单人镜头没有关系前景时，直接写人物与景别。 | 孤立、主观体验或关系断裂必须由可见构图、距离、视线和表演表达。 |
| ML20 | 正侧面双人镜头适合僵持、审讯、谈判和明确对抗。 | 长时间纯侧拍容易失去面部信息，应结合调度或其他角度。 |
| ML21 | 正面镜头强化人物的控制、决断、自我呈现或直面现实。 | 正面构图越居中，人物越显得稳定、强势或被强迫面对。 |
| ML22 | 背面或后侧镜头用于延迟身份、隐藏表情、表现观察或疏离。 | 不能在需要观众准确读取关键情绪时持续遮住人物面部。 |
| ML23 | 平视角度是自然对白和客观观察的默认角度。 | 不应用无理由的高低角度制造虚假戏剧性。 |
| ML24 | 略低机位用于提升人物权力、魅力、威胁或稳定性。 | 低机位的强度应与剧情权力匹配，普通人物不能无原因拍成英雄或反派。 |
| ML25 | 高机位用于表现弱势、被审视、迷失或空间压制。 | 高机位不等于角色一定懦弱，也可用于冷静展示其被包围的处境。 |
| ML26 | 垂直俯拍用于展示空间布局、群体结构、尸体、轨迹或命运式隔离。 | 不应仅因“有电影感”而使用，必须让俯拍提供普通角度无法提供的信息。 |
| ML27 | 贴地低机位用于强化脚步、逼近、跌落、巨大物体或地面危险。 | 必须提前建立主体位置，避免观众只看到脚却不知道人物是谁。 |
| ML28 | 荷兰角只用于空间或心理明显失衡。 | 不可作为一般紧张戏的默认角度；恢复平稳时应回到水平构图。 |
| ML29 | 广角焦段用于强调空间深度、近远距离和人物与环境的关系。 | 靠近人脸时会造成透视变形，除非刻意表达不安、压迫或主观扭曲。 |
| ML30 | 中等焦段用于自然人物比例和稳定空间关系。 | 普通对白、走位和主镜头优先使用，是横屏剧集的基础焦段。 |
| ML31 | 长焦用于压缩空间、强化窥视感、隔离人物或制造无法逃离的拥挤感。 | 不应把长焦简单理解为“高级感”；过度使用会失去空间深度。 |
| ML32 | 浅景深用于限定角色注意力、隐藏背景信息或强调主观体验。 | 关键动作同时发生在不同景深时，不应把必要信息全部虚化。 |
| ML33 | 深景深用于让前景、中景和后景中的关系同时成立。 | 适合权力场面、群戏、悬疑信息和背景人物反应，但构图必须有明确层级。 |
| ML34 | 焦点转移必须对应注意力、认知或权力的转移。 | 禁止为了展示技巧而在无关物体之间反复拉焦。 |
| ML35 | 固定镜头用于等待、压抑、冷静观察、尴尬停顿和不可逃避的现实。 | 固定不等于没有变化，人物调度、表演和画内信息仍需发展。 |
| ML36 | 推镜必须对应人物心理收紧、信息确认、危险逼近或权力加强。 | 不能把每句重要台词都写成缓慢推进；同一场戏中的推镜要有强弱层级。 |
| ML37 | 拉镜用于关系疏远、人物被环境吞没、结果揭示或从主观退回客观。 | 拉镜结束后的新增空间信息必须具有叙事价值。 |
| ML38 | 水平摇镜用于跟随视线、连接人物、揭示画外主体或完成信息交接。 | 摇镜应有明确起幅和落幅，不能只写“镜头摇到另一人”。 |
| ML39 | 垂直摇镜用于揭示高度、身份、身体状态或从局部过渡到整体。 | 从脚摇到脸容易程式化，应确保揭示顺序与剧情认知一致。 |
| ML40 | 横向轨道运动用于重新排列人物、揭示遮挡信息或改变阵营构图。 | 横移不仅是跟拍，落幅必须形成与起幅不同的关系结构。 |
| ML41 | 前后跟拍用于保持人物行动连续、强化主观进入感或展示路径。 | 跟拍过程中应有新的障碍、人物或信息进入画面，避免无内容地陪人物走路。 |
| ML42 | 环绕镜头用于关系重新定义、情绪眩晕、亲密升级或局势逆转。 | 必须说明环绕方向、轴线变化和最终落幅，防止空间关系混乱。 |
| ML43 | 升降、摇臂或吊臂运动用于从个人命运扩展到整体局势，或反向进入具体人物。 | 不应将升降镜头当作普通场景开场的固定仪式。 |
| ML44 | 手持镜头用于身体危险、情绪不稳定、临场感和失控。 | 手持幅度应受控，不能用随机抖动代替动作设计。 |
| ML45 | 稳定器或流畅长跟镜头用于沉浸式空间穿行、仪式感和连续关系变化。 | 流畅不等于缓慢，运动速度应配合人物步速和场景压力。 |
| ML46 | 变焦属于明显风格化手段，用于认知冲击、窥视、喜剧强调或时代风格。 | 普通推近优先使用物理移动；变焦和Dolly Zoom只有在叙事上有明确意义时调用。 |

# 第二部分：剪辑语言规则

| ID | 规则 | 功能与限制 |
|---|---|---|
| ED01 | 剪辑点应落在信息变化、情绪变化、动作变化或关系变化上。 | 不能仅因镜头达到预设秒数就切换。 |
| ED02 | 每次切镜都应回答“为什么现在必须换一个观看位置”。 | 若新镜头没有提供新信息、新情绪或更准确的关系，优先保留原镜头。 |
| ED03 | 对白不采用机械的“谁说话切谁”。 | 可以留在听者反应、保持双人镜头，或让说话者留在画外。 |
| ED04 | 关键台词的重心不一定是说话者，而可能是听者的理解过程。 | Agent应判断台词改变的是谁，并把镜头优先交给发生变化的人。 |
| ED05 | 动作剪辑优先在动作进行中切换。 | 利用动作匹配隐藏切点，使动作在两个景别间保持连续。 |
| ED06 | 情绪剪辑可以在动作完成后延迟切换。 | 给人物保留反应和余韵，避免每个动作结果一出现就立即切走。 |
| ED07 | J-cut用于声音先行，引导观众进入下一场或提前制造预期。 | 下一场声音必须能自然连接当前情绪或信息。 |
| ED08 | L-cut用于让上一镜声音延续到下一镜，保留情绪和关系。 | 适合对白反应、回忆触发和环境连续，不应造成说话者身份混乱。 |
| ED09 | Match Cut应建立形状、动作、方向、声音或概念上的明确联系。 | 不能仅因为两个画面颜色相似就强行匹配。 |
| ED10 | Smash Cut用于强烈情绪、音量、空间或时间反差。 | 反差必须服务剧情，不能频繁使用以免失去冲击力。 |
| ED11 | Jump Cut用于时间跳跃、心理断裂、焦躁或风格化压缩。 | 常规连续对白中禁用无意跳切。 |
| ED12 | 平行剪辑用于两个行动互相影响、争夺时间或产生因果预期。 | 两条线必须存在明确的时间、目标或主题关系。 |
| ED13 | 交叉剪辑加速时，应逐渐缩短镜头而非从一开始就保持同样快。 | 节奏升级必须形成递进。 |
| ED14 | 反应镜头只在反应改变剧情理解时单独切出。 | 普通点头、眨眼、惊讶不必全部独立成镜。 |
| ED15 | 群体反应应选择最有叙事价值的代表人物。 | 避免依次切遍所有旁观者，造成短剧式重复强调。 |
| ED16 | 信息特写应在观众需要识别信息的时刻出现。 | 过早给出会失去悬念，过晚给出会造成理解障碍。 |
| ED17 | 剪辑必须保留动作起因、主要过程和结果中的必要部分。 | 可以省略重复过程，但不能只给动作起势后直接跳到无法理解的结果。 |
| ED18 | 重要关系变化前后应保留视觉对照。 | 通过相似构图、不同距离或不同景别，让观众感知权力和心理位置发生变化。 |
| ED19 | 转场应继承上一场的动作、声音、方向、构图或情绪。 | 禁止无功能地使用黑场、空镜和复杂特效转场。 |
| ED20 | 一场戏的最后一个镜头必须完成余韵、悬念或方向引导。 | 不应只因对白结束就切场，应明确观众离场时带走的核心信息。 |

# 第三部分：Blocking人物调度规则

| ID | 规则 | 功能与限制 |
|---|---|---|
| BL01 | 镜头设计前必须建立人物初始位置、目标位置和移动路径。 | 不允许先设计运镜，再临时安排人物配合摄影机。 |
| BL02 | 每次明显走位都应对应目标、情绪、权力或信息变化。 | 无目的踱步、绕圈和频繁转身会削弱表演可信度。 |
| BL03 | 靠近通常表示施压、试探、亲密或寻求确认。 | Agent必须明确是哪一种动机，不能只写“人物缓慢靠近”。 |
| BL04 | 后退通常表示防御、失去权力、恐惧或主动拉开关系。 | 后退路径应受到空间和障碍物约束，不能无限向后退。 |
| BL05 | 一方切断另一方通往门口或出口的路径，可以建立控制与威胁。 | 必须在前镜建立出口位置，观众才能理解“挡路”的意义。 |
| BL06 | 人物进入画面中央通常表示掌控、被迫成为焦点或获得主导权。 | 中央位置的意义取决于其他人物如何退让、围观或反应。 |
| BL07 | 人物被推向画面边缘可以表现孤立、压迫和失去空间。 | 需保留合理的视线空间，除非刻意制造窒息感。 |
| BL08 | 前景人物通常具有视觉权力或遮挡能力。 | 弱势人物也可以进入前景，但应说明这是主观贴近还是暂时反击。 |
| BL09 | 后景人物可以承担观察、监视、等待、潜在威胁或被排除。 | 后景信息必须清晰到足以被识别，但不能抢走主Beat。 |
| BL10 | 站立者相对坐着者通常具有高度优势。 | 若坐着者才是真正掌权者，应通过稳定构图、中心位置和他人围绕来反转高度关系。 |
| BL11 | 起身是一种权力动作，应对应决定、反击、结束谈话或威胁升级。 | 不应让人物为了增加运动镜头而反复坐下起身。 |
| BL12 | 坐下可以表示掌控、拒绝被挑衅、疲惫、投降或进入正式谈判。 | 必须结合人物状态和他人站位判断，不能统一解释为弱势。 |
| BL13 | 背对对方可以表示拒绝、信任、隐藏情绪或有意挑衅。 | 背对时必须保证关键台词仍有表演载体，如侧脸、肩颈或镜中反应。 |
| BL14 | 转身应发生在人物认知、注意力或关系方向改变时。 | 无意义的频繁回头会产生舞台化调度。 |
| BL15 | 两人并肩适合共同观察、临时联盟、共享秘密或尚未直接面对冲突。 | 并肩人物的视线目标必须明确，避免看向无意义的画外。 |
| BL16 | 两人面对面适合明确对抗、谈判、告白和无法回避的交流。 | 面对面时间过长会僵硬，应通过距离、高度和位置变化推进。 |
| BL17 | 一前一后适合表现追随、控制、监视、保护或情绪错位。 | 前后关系必须结合视线和行进方向保持清楚。 |
| BL18 | 人物擦肩而过可以表达关系错位、拒绝沟通或权力变化。 | 应明确谁主动让路、谁不让路、是否发生眼神或身体接触。 |
| BL19 | 围绕某个角色形成半圆、封闭圈或多方向压力，可以表现审判和包围。 | 必须留出轴线与剪辑通道，避免多人方位无法维持。 |
| BL20 | 亲密调度依赖距离逐级变化，而不是突然从远距离进入身体接触。 | 建议经过视线确认、试探性靠近、私人距离突破和接触四个层级。 |
| BL21 | 动作场面调度优先保证目标、障碍、路径和空间结果清晰。 | 不应为了复杂招式牺牲谁攻击谁、人物为何移动以及动作结果。 |
| BL22 | 每场戏结束时，人物最终位置应体现这一场造成的关系结果。 | 谁留在中心、谁离开、谁被困住、谁背对谁，都应成为场景结论的一部分。 |

# 第四部分：180°轴线与空间连续性规则

| ID | 规则 | 功能与限制 |
|---|---|---|
| CT01 | 每场戏开始前必须确定主轴线。 | 主轴通常由两名核心人物、人物与目标物、行进方向或攻击方向形成。 |
| CT02 | Agent应记录主要人物位于轴线的哪一侧。 | 后续镜头必须维持人物左右关系，除非明确设计越轴。 |
| CT03 | 正反打镜头中，两人视线方向必须互相对应。 | A看画面右侧时，B通常应看画面左侧。 |
| CT04 | 双人主镜头应先建立双方位置，再进入更窄的正反打。 | 若未建立空间，单人镜头容易让观众误解人物方位。 |
| CT05 | 越轴必须具有明确的叙事或情绪目的。 | 可用于权力反转、认知失衡和关系重置，但不能由随机机位造成。 |
| CT06 | 合法越轴可通过轴上镜头、中性正面镜头或摄影机连续移动完成。 | 观众需要看到摄影机或人物如何跨越轴线。 |
| CT07 | 人物主动跨过轴线时，可以建立新的轴线。 | 新轴线建立后，后续镜头必须按照新关系持续。 |
| CT08 | 多人场面应为每组主要关系建立局部轴线。 | Agent应明确当前镜头服务哪一组人物，避免所有轴线同时混用。 |
| CT09 | 长桌、会议、审判和宴会场景必须建立座位图。 | 座位左右、主位方向、入口和窗户位置均属于连续性硬信息。 |
| CT10 | 人物进入和离开画面的方向应与空间路径一致。 | 从画面右侧离开后，下一镜通常应从对应方向继续，除非转场明确改变地理方向。 |
| CT11 | 追逐场景应维持主要运动方向。 | 追逐者和被追者应朝同一总体方向移动，反向镜头必须提前建立转弯或折返。 |
| CT12 | 门、窗、楼梯、走廊和家具位置不得在反打中镜像。 | AI生成场景尤其要明确左右位置和人物相对方位。 |
| CT13 | 道具朝向必须服从人物使用方向和场景透视。 | 剑柄、枪口、餐具、手机屏幕、车辆方向不能在镜头间自行翻转。 |
| CT14 | 人物惯用手或剧情指定用手必须保持一致。 | 左手持剑、右手受伤等信息需写入每个相关镜头。 |
| CT15 | 服装破损、伤口、血迹、湿润程度和道具状态必须按时间递进。 | 不能在后镜恢复到早先状态。 |
| CT16 | 光源方向应与场景母版和人物位置保持一致。 | 人物移动后，主光角度可以变化，但不能无理由左右翻转。 |
| CT17 | 背景人物的位置和动作应保持基本连续。 | 群演可以自然移动，但不能在相邻镜头瞬间交换位置或消失。 |
| CT18 | 镜头进入更近景别时，应保留足够的背景线索确认空间。 | 如果必须完全清除背景，应先通过主镜头建立位置。 |
| CT19 | 时间跳跃、地点变化或空间重置必须有明确转场标记。 | 可通过字幕、环境变化、声音、动作匹配或重新建立镜头完成。 |
| CT20 | Agent完成分镜后必须进行一次空间连续性复核。 | 检查轴线、左右、视线、进出方向、道具、伤口、光源和人物最终位置。 |

# 第五部分：视线规则

| ID | 规则 | 功能与限制 |
|---|---|---|
| EL01 | 每个单人镜头必须明确人物看向谁或什么。 | 禁止只写“看向前方”而没有具体画外目标。 |
| EL02 | 视线方向必须与人物空间位置一致。 | 人物在对方左侧时，其视线方向应与既定轴线匹配。 |
| EL03 | 视线高度必须匹配双方身高、站坐状态和距离。 | 坐着的人看站着的人应略微抬眼，除非刻意避免对视。 |
| EL04 | 看向近处的人与看向远处的人，眼球角度和焦点状态应不同。 | 不应让人物用同一种空洞视线完成所有观看动作。 |
| EL05 | 先给人物看，再给其所见，可以制造发现和期待。 | 适合悬疑、惊讶、观察和信息揭示。 |
| EL06 | 先给目标，再给人物反应，可以强调信息本身的冲击。 | 适合观众已经知道危险，而人物刚刚意识到的场景。 |
| EL07 | POV镜头必须与前后人物视线高度、方向和距离匹配。 | POV不等于随意拍摄目标物的特写。 |
| EL08 | 画外视线应给观众足够的视线空间。 | 人物看向画面右侧时，通常应在右侧留出空间。 |
| EL09 | 故意压缩视线空间可制造受困、拒绝和压迫感。 | 必须是有意识的构图，不能由错误头部空间造成。 |
| EL10 | 避免直接对视可以表现隐瞒、愧疚、权力不对等或情感回避。 | Agent应写明人物在看手、门、地面、镜子还是其他对象。 |
| EL11 | 第一次建立真正对视应作为关系Beat处理。 | 可以通过停顿、景别收紧、焦点变化或运动停止进行强调。 |
| EL12 | 多人对话中，视线必须明确指向当前发言者或真正关注对象。 | 群体不能统一僵硬地看向同一位置，除非剧情要求。 |
| EL13 | 镜中视线和反射视线必须符合镜面几何关系。 | 人物看镜中对方时，不等于在现实空间里直接看向对方。 |
| EL14 | 视线断开、重新连接或转移，应对应注意力或关系变化。 | 视线变化可以独立构成一个Beat，不应被无意义动作掩盖。 |

# 第六部分：动作衔接规则

| ID | 规则 | 功能与限制 |
|---|---|---|
| AM01 | 每个关键动作应拆分为准备、启动、主要过程、接触或结果。 | 分镜不一定展示全部阶段，但必须明确哪些阶段由哪些镜头承担。 |
| AM02 | 相邻镜头中的动作幅度、速度和身体方向必须连续。 | 不能上一镜刚抬手，下一镜已经完成多个未交代动作。 |
| AM03 | 动作中切换景别时，应在同一动作阶段匹配。 | 例如中景开始起身，近景接人物继续站起，而不是重新坐着再起一次。 |
| AM04 | 动作重叠可以轻微重复关键瞬间，以增强冲击和剪辑弹性。 | 重复幅度应小，不能让动作明显发生两次。 |
| AM05 | 接触类动作必须建立双方身体位置和受力方向。 | 推、拉、抓、撞、拥抱、亲吻和击打均不能只写结果。 |
| AM06 | 武器动作必须交代握持手、武器朝向、目标和轨迹。 | 剑柄、剑尖、枪口和攻击方向属于连续性硬信息。 |
| AM07 | 递交道具时，应交代谁先伸手、谁接住、道具在哪只手。 | 特写和中景中的手部方向必须一致。 |
| AM08 | 开门、关门和穿门动作必须保持人物所在侧和门扇方向一致。 | 防止下一镜人物突然出现在门的另一侧。 |
| AM09 | 坐下和起身动作应保持椅子位置、身体朝向和手部支撑连续。 | 不能在切镜后改变人物面对方向。 |
| AM10 | 跌倒、被推和被击中应先建立力的来源，再给身体结果。 | 除非刻意隐藏攻击者，否则不能只给人物突然倒地。 |
| AM11 | 追逐中的转弯、停顿和折返必须提前建立障碍或目标。 | 人物不能为了改变摄影方向而无理由转向。 |
| AM12 | 亲密动作应通过距离、视线、手部和身体重心连续推进。 | 不应从无接触状态跳到无法解释的贴近姿势。 |
| AM13 | 人物拿起或放下道具后，后续镜头必须持续追踪其状态。 | 道具不能在未交代的情况下换手、消失或重新回到桌面。 |
| AM14 | 动作后的反应时间应符合力度和人物状态。 | 强烈冲击后人物不能立即恢复正常对话，除非角色设定或剧情明确要求。 |
| AM15 | 声音动作必须与画面动作同步或有明确的画外来源。 | 拍门、落杯、拔剑和撞击声不能早于或晚于动作而没有设计依据。 |
| AM16 | Agent完成动作场景后必须按时间顺序复述人物动作链。 | 若无法用一句连续动作说明整段过程，说明动作衔接仍存在缺口。 |

# 第七部分：节奏设计规则

| ID | 规则 | 功能与限制 |
|---|---|---|
| RH01 | 镜头时长由表演、对白、动作和情绪变化决定，不设统一秒数。 | 横屏剧集不能强制每镜两到三秒。 |
| RH02 | 一个镜头应至少持续到主要信息被观众读取。 | 复杂多人画面、文字信息和细微表演需要更长阅读时间。 |
| RH03 | 快节奏不等于大量短镜头，而是信息变化密集且没有冗余。 | 一个调度丰富的长镜头也可以具有快速节奏。 |
| RH04 | 慢节奏不等于人物停住不动。 | 慢节奏镜头中仍可通过呼吸、视线、焦点和距离积累压力。 |
| RH05 | 一场戏应有清楚的节奏起点、升级段、峰值和余韵。 | 所有镜头强度相同会导致场景平坦。 |
| RH06 | 景别通常随着情绪升级而逐渐收紧。 | 关系需要重新建立或结果需要释放时，可以突然拉远。 |
| RH07 | 运镜速度应与心理速度对应。 | 缓推适合确认和压迫，快速横移适合突发信息，突然停机适合认知冲击。 |
| RH08 | 剪辑速度应在关键Beat前后形成对比。 | 高潮前可延长停顿，高潮后可短暂静止或拉远。 |
| RH09 | 对白节奏应保留抢话、停顿、未完成句和沉默的功能。 | 不应把所有对白剪成整齐的单句正反打。 |
| RH10 | 沉默是一种主动节奏单位。 | 沉默期间必须有视线、身体、空间或声音变化支撑。 |
| RH11 | 反应镜头的长度由人物理解信息所需时间决定。 | 不能所有反应统一停留一秒。 |
| RH12 | 重复信息应通过镜头变化升级，而不是重新说明同一内容。 | 第二次威胁应改变距离、位置或后果，不能只是换一句台词。 |
| RH13 | 动作场面应在清晰与速度之间保持平衡。 | 起势和结果通常需要更清楚，中间过程可适当加速。 |
| RH14 | 悬疑节奏依赖信息控制，不依赖单纯拖延。 | 每个延迟段必须增加新的疑问、危险或错误判断。 |
| RH15 | 爱情与亲密场景的节奏应由距离和许可逐级推进。 | 过快会失去拉扯，过慢但没有关系变化会显得拖沓。 |
| RH16 | 群戏节奏应通过发言权和视觉中心转移推进。 | 不能仅依靠依次切换每个人的近景。 |
| RH17 | 场景结尾应比场景中段更明确地改变状态。 | 至少应改变信息、关系、目标、危险或下一步行动中的一项。 |
| RH18 | Agent应在输出后检查连续三镜是否景别、角度和运动完全相同。 | 若完全相同且没有刻意压迫设计，应调整视觉节奏。 |

# 第八部分：戏剧Beat对应镜头模板

以下模板不是固定镜头数量，而是镜头设计顺序。Agent应根据场景长度、表演和空间删减或组合。

| ID | Beat | 推荐镜头模板 |
|---|---|---|
| BT01 | 角色进入 | 先建立空间与已有关系 → 角色从有意义的入口进入 → 场内人物反应或空间重新排列 → 用中景或近景确认角色状态。 |
| BT02 | 第一次正式见面 | 双方尚未完全同框的观察镜头 → 视线匹配 → 双人关系镜头 → 第一次对视时适度收紧或停止运动。 |
| BT03 | 怀疑产生 | 保持表面正常的主镜头 → 细节或不一致信息 → 怀疑者反应但不立即确认 → 用遮挡、焦点或单人镜头表现心理分离。 |
| BT04 | 谎言出现 | 说谎者不一定获得近景 → 优先观察听者是否相信 → 保留说谎者身体或手部异常 → 结尾落在尚未揭穿的关系状态。 |
| BT05 | 威胁升级 | 建立双方可退让的空间 → 威胁者靠近或切断出口 → 景别收紧、前景遮挡加重 → 被威胁者的选择或拒绝形成结尾。 |
| BT06 | 信息发现 | 人物注意力改变 → 视线或动作引导到信息 → 给足识别时间 → 回到人物理解过程 → 明确发现后的新目标。 |
| BT07 | 真相揭露 | 先控制观众知道多少 → 关键证据或台词出现 → 留在受影响最大的人物反应 → 必要时拉远展示关系或局势被重新排列。 |
| BT08 | 权力反转 | 前段明确原掌控者位置 → 弱势者获得信息、道具或决定 → Blocking中心位置交换 → 原掌控者反应 → 新权力关系以双人或多人镜头确认。 |
| BT09 | 情绪崩溃 | 先维持控制状态 → 出现最后触发点 → 镜头停止、收紧或失去稳定 → 让身体反应先于解释 → 用余韵而非立即对白收尾。 |
| BT10 | 告白或承认 | 两人共享空间但存在距离 → 一方决定说出 → 镜头优先保留听者反应 → 对视重新建立 → 是否靠近或分开决定结果。 |
| BT11 | 亲吻或亲密突破 | 视线和呼吸变化 → 私人距离缩短 → 手部或身体先建立许可与接触 → 关键动作保持可执行遮挡 → 动作后给关系结果而非立即切走。 |
| BT12 | 攻击或突发暴力 | 先建立攻击者、目标和距离 → 给出触发动作 → 清楚展示主要冲击 → 结果和旁观反应 → 明确场面进入的新状态。 |

# 第九部分：不同类型场景的镜头公式

## SC01 普通对白场景

**公式：空间建立 → 共享关系镜头 → 根据话语权切换单人覆盖 → 关键反应 → 关系结果。**

开场可以使用双人中景或中全景建立关系，但不机械要求每场先给双人镜头。关系稳定且需要同时读取双方距离时可以同框；出现隐瞒、冲突或心理分离后，进入过肩、单人和真正改变理解的反应镜头。关键台词应根据“谁发生变化”决定镜头落点，不采用机械正反打。

## SC02 争吵、谈判与权力对抗

**公式：原始权力构图 → 语言试探 → 距离或高度变化 → 景别收紧 → 权力反转或关系破裂。**

应明确谁占据中央、出口、主位或更高位置。随着冲突升级，人物应通过起身、逼近、绕过桌子、挡路或进入前景改变权力。不要仅通过音量和快速切镜表达争吵。

## SC03 爱情、暧昧与亲密场景

**公式：共享空间 → 视线建立 → 距离逐级缩短 → 私人空间被突破 → 身体接触 → 动作后的关系确认。**

双人镜头用于建立共享空间、距离变化和接触结果；单人、过肩、反应近景与身体/道具特写用于拆开双方不同步的欲望、许可、犹豫、退让、试探和拒绝。亲密、暧昧、拉扯及重要双人/三人关系戏的每个关键关系 Beat，必须至少有一个可独立读取变化的单人、过肩反应、近景/大近景或具有关系功能的身体/道具特写，共享双人/多人镜头不能替代。不能无功能地堆积嘴唇、眼睛和手指；每次靠近、停顿、触碰或退开都必须产生新的关系状态，并把镜头交给真正发生变化的人或细节。该规则不转化为固定镜头比例。

## SC04 悬疑与潜在危险场景

**公式：建立正常秩序 → 放入异常但不立即解释 → 控制谁先发现 → 延迟确认 → 危险进入同一空间。**

可以利用深景深、遮挡、长焦、画外声和背景动作。悬疑来自观众与人物掌握信息的差异，而不是通过持续黑暗、慢推和空镜硬拖时间。

## SC05 调查、发现与证据场景

**公式：角色目标 → 搜索路径 → 错误或次要线索 → 关键细节 → 识别信息 → 决定下一步。**

搜索过程应有空间方向和注意力变化，不要连续堆叠手部特写。证据出现时先保证可识别，再给人物理解和判断，最后明确该证据如何改变行动。

## SC06 真相揭露与反转场景

**公式：维持错误认知 → 植入矛盾信息 → 关键证据或行动出现 → 受影响者反应 → 重新建立全场关系。**

揭露前不要过早用镜头暗示答案。揭露后不仅需要近景反应，还应通过双人、多人或拉远镜头展示谁失去位置、谁获得控制以及其他人如何重新站队。

## SC07 打斗与近身动作场景

**公式：空间和双方目标 → 动作起势 → 中景展示主要技术和身体关系 → 特写强化关键冲击 → 全景或中全景确认结果。**

打斗必须优先清楚，其次才是速度。每轮动作应有发起者、目标、方向和结果。近景与快速剪辑不能掩盖空间错误，武器和左右手必须连续。

## SC08 追逐与逃亡场景

**公式：逃跑原因 → 总体运动方向 → 追赶距离 → 障碍改变路径 → 距离缩短或拉开 → 追逐阶段结果。**

通过地标、门口、走廊、街道和转弯维持地理方向。交叉剪辑应让观众理解双方距离变化，不能只展示两人分别奔跑。每次切换都应更新危险程度。

## SC09 恐怖与惊吓场景

**公式：建立空间安全规则 → 放入异常声音或细节 → 角色调查或否认 → 视线受限 → 危险出现或规则被打破 → 后果。**

惊吓前应建立观众对空间的预期。Jump Scare需要位置和时间上的准备，不能让危险从未建立的方向突然出现。持续恐怖更多依靠等待、背景和画外空间。

## SC10 喜剧场景

**公式：建立正常预期 → 信息错位或行为升级 → 保持镜头让尴尬发展 → 在最佳时点切到反应或结果。**

喜剧不宜过早切碎。固定双人或多人镜头通常有利于观众同时看到原因和反应。风格化变焦、快速摇镜和突然切出可以使用，但必须服务明确笑点。

## SC11 群戏、会议、宴会与审判场景

**公式：建立座位与阵营 → 明确发言中心 → 通过视线和Blocking转移话语权 → 关键人物打破秩序 → 全场关系重新排列。**

必须先制作空间图和座位图。不要依次给所有人单人镜头；优先使用多人构图、代表性反应和前后景关系。主位、入口、站立者和沉默者都应具有功能。

## SC12 蒙太奇、时间压缩与过渡场景

**公式：明确蒙太奇目标 → 选择具有递进关系的动作或信息 → 使用动作、构图、声音或概念匹配连接 → 以明确结果结束。**

蒙太奇中的每个镜头必须推动时间、能力、关系、调查或计划进展。禁止只堆积气氛空镜。镜头顺序应形成开始、发展和结果，而不是可随意交换。

# Agent输出约束

生成横屏分镜时，每个镜头至少应包含：

- 场次与镜号；
- 建议时长；
- 景别；
- 机位高度与拍摄角度；
- 焦段或空间压缩倾向；
- 运镜方式及起幅、过程、落幅；
- 人物初始位置与Blocking；
- 画面内容和关键动作；
- 人物视线；
- 对白、环境声与关键音效；
- 剪辑点及与前后镜头的衔接；
- 当前镜头承担的主要叙事功能（内部先确定，不作为成稿标签输出）；
- 轴线、左右手、道具、伤口和方向连续性状态（内部复核，不作为成稿备注输出）。

Agent不得使用以下模糊描述：

- “镜头有电影感”；
- “镜头缓慢移动”但不写方向；
- “人物发生互动”但不写具体动作；
- “大家震惊”但不确定主要反应者；
- “镜头切换”但不说明切点；
- “从不同角度拍摄”但不说明机位；
- “人物看向前方”但不说明观看对象；
- “围绕人物运镜”但不说明环绕方向与落幅；
- “快速剪辑”但不说明动作、信息和节奏递进；
- “用特写加强情绪”但不说明具体特写对象与戏剧功能。

最终判断标准不是镜头种类是否丰富，而是：

**观众能否清楚理解空间、动作和人物关系；镜头是否随着戏剧Beat发生变化；每次切镜和运镜是否具有明确原因；场景结束时人物关系是否已在画面中产生可见变化。**

## 已确认的融合补充

以下为用户后续确认的执行口径；与上方较早输出措辞冲突时，本节优先：

- 固定七列表头为`场次｜镜号｜时长｜摄影机｜画面内容｜音效｜剪辑衔接`，所有要求按`output-schema.md`映射进七列。
- 每镜在“摄影机”中直接写`50mm`等具体毫米焦段；机位高度允许可执行的相对描述。
- “摄影机”只简写主体与景别、焦段、位置、高度角度以及固定/手持/运动类型和方向。运镜触发、过程、人物 Blocking 与落幅由“画面内容”沿同一时间线承担。
- “画面内容”不显示主要功能、第一主体、轴线术语、连续性证明或导演解释；这些判断保留在内部创作与复核层。
- 双人景别固定为：双人全景头部到脚部，双人中景头部到腰部，双人中近景头部到胸部，双人近景头部到脖子且基本等同于两人脸部近景；不再设置额外的中间双人景别名称。
- 常规银幕方向、逐镜画面左右、入画方向和前景虚实留到 Stage 3 draft；Stage 1 只在第一次建立双人/多人关系或构图关系真实改变时写必要画面位置。
- 时长默认以`5–10s`为主；`10–20s`极少使用；`20–30s`只接受镜号级授权；绝不超过`30s`。
- 每镜最多四名主动人物，超过四人只接受镜号级授权。
- 轴线是硬规则，但允许有动机且可读的合法越轴；建立新轴线后必须持续维持。
- 关键 Beat 的信息与情绪都必须清楚，但可以由同一镜头承担，不强制拆成两个镜头。
- 不可缺少的信息与反应镜头属于主序列；必要覆盖只保护替代、剪辑点或 AI 生成风险。
