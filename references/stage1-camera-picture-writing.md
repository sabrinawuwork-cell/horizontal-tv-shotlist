# Stage 1 摄影机与画面书写规范

本文件规定 Stage 1 七列成稿中`摄影机`与`画面内容`的写法。它只改变成稿表达，不降低剧情忠实、镜头动机、空间轴线、动作物理和连续性硬规则。

## 摄影机

`摄影机`负责主体与景别、具体焦段、摄影机位置、高度与角度、固定/手持或具体运动。景别和焦段服务本镜观看任务、人物关系和真实距离，不堆叠术语。

统一顺序：`主体＋景别 → 具体焦段 → 摄影机相对位置 → 高度与角度 → 固定/手持/运动方式`。

单人镜头必须写清摄影机位于人物左前方、右前方、左侧、右侧、左上方、右上方、左下方或右下方，并说明平视、俯拍、仰拍或贴近身体平面。禁止只写`侧面拍摄`，也禁止用`机位在两人左侧/右侧`描述单人镜头。

双人及多人镜头以主体加景别表达，例如`A与B双人全景`、`A与B双人近景`。双人景别使用固定身体截取范围：双人全景为头部到脚部，双人中景为头部到腰部，双人中近景为头部到胸部，双人近景为头部到脖子，基本等同于两人脸部近景。摄影机列只写景别名称，不重复解释截取范围。第一次建立人物关系所需的画面左、右、中央和前后层次写在`画面内容`；关系未改变时不重复。

过肩镜头直接写成`过A的左/右肩拍B的中景`或`过A的左/右肩拍B的近景`，不再添加机位在两人哪侧、肩膀画面位置、前景虚实或谁是主体；反打必须重新写清过谁的哪侧肩拍谁。

普通单人镜头直接写`A的近景`。若不是过肩镜头但前景确有虚化人物或物体，直接写明`前景为B的侧脸`、`前景为桌上的酒杯`等可见事实。身体和道具特写保留主人、连续性需要的左右归属、动作与接触对象；摄影机的起幅与落幅由`画面内容`展开。

POV统一只写`POV中景`，依靠前镜视线确认视点主人，不使用其他 POV 景别名称。视点人物本人不可见时，`摄影机`与`画面内容`都不出现其名字。

每镜必须直接写具体毫米数，例如`50mm`。焦段的可见效果可以补充，但不能代替数值。固定镜头必须写`固定`；手持可以不位移，只保留轻微摇晃、呼吸或不稳定感。

摄影机移动时，本列只写运动类型、实际方向和必要速度，例如`向左横移`、`缓慢推近`、`手持跟随`。起幅、触发、过程、落幅与停止时机全部在`画面内容`详细展开。运镜必须揭示信息、跟随动作、增加压力、改变人物关系或标记转折，禁止装饰性运动。

载具、房间或场景本身摇晃、颠簸或失重时，写清摄影机锁定场景还是相对场景独立运动，避免`固定`与画面摇晃互相矛盾。

## 画面内容

`画面内容`是本镜可见动作、变化和台词表演的权威来源。每格只写一段连续自然语言，不写关键词清单，也不重复独立`时长`列。

按实际发生顺序写：开镜时人物正在做什么 → 本镜具体动作 → 真正发生的反应或变化 → 角色在什么动作、视线、接触或停顿中说出逐字台词 → 可见结果 → 镜头最终状态。

摄影机运动和画面属于同一镜头事件。本列写清触发运镜的动作、反应、台词或声音，以及运镜完成前后的可见变化、落幅与停稳时机；不重复完整摄影术语。

只写摄影机真正看得到的人物、身体、道具和行为。不可见人物不得为说明动作来源、关系或主观视角而进入描述。POV中视点人物不可见时也不出现。

第一次建立双人或多人关系时写清关键人物画面左、右、中央和必要前后层次。之后沿用最近一次有效建立；只有明显换位、遮挡、出画、入画、取得关键道具、打开门/窗帘等屏障或关系重组时才重新描述位置。

常规银幕方向、逐镜入画方向、画面边缘控制和前景虚实留到 Stage 3 draft。Stage 1 通常不写人物向画面左/右移动，保留真实世界目标、人物自身左右侧、施力方向、接触和结果。

手、手臂、肩、腿、脚、身体侧面、侧脸、武器和道具必须写明主人；连续性依赖左右侧时写清左/右。对称动作直接写双手、双臂、双腿或双膝。

动作必须写清谁发起、作用于谁或什么、必要真实方向、接触点和可见结果。例如：`Damon双手推开Teresa的双肩，Teresa身体失去支撑，向后撞上洗手台。`

情绪转为可见、可演的行为，例如避开视线、抬眼看对方、咬住下唇、呼吸停住、手指松开、身体退后或眼睛不移开。禁止用`加强压迫感`、`突出情绪`、`充满欲望`、`权力发生变化`、`脸上只剩决定`或`眼里的反驳塌下`等抽象或文学表达代替表演。

所有原文台词逐字写入本列，并绑定发声时的动作、视线、接触、持物变化或可见停顿。例如：`Teresa右手抓住Damon的衬衫领口，把他拉近时说：“Right now, I want you.”`同一句台词跨镜时，每镜只保留本镜实际说出的连续部分。说话人、原文语言和发声状态不得改写、概括或遗漏。

`O.S.`、`VO`、电话或对讲机台词保持原发声状态并绑定画面中的动作或接收反应，不让画外角色进入画面，不给 VO 角色添加口型。

本列不写人物内心解释、导演设计原因、主要功能/第一主体标签、轴线术语、连续性证明、AI生成方法、模型限制或 Stage 3 才需要的逐镜银幕方向和前景虚实。把判断转化为实际可见动作和结果。

## 横向一致性检查

- 摄影机拍摄的人物真实出现在画面内容中。
- 关键动作在当前景别和角度下可见。
- 运镜触发与动作、台词或声音发生在同一时刻。
- 起幅承接前镜状态，落幅对应本镜动作结果。
- 单人镜不意外写入不可见角色。
- 人物自身左右、道具位置和接触关系前后连续。
- 当前构图不被要求同时看清无法容纳的主体。

## 双人景别固定范围

- `双人全景`：两人均从头部到脚部可见。
- `双人中景`：两人均从头部到腰部可见。
- `双人中近景`：两人均从头部到胸部可见。
- `双人近景`：两人均从头部到脖子可见，基本等同于两人脸部近景。

焦段和透视选择不得改变上述身体截取定义。不再设置介于这些景别之间的额外双人景别名称。
