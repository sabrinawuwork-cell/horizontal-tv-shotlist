# 横屏剧集导演核心

本文件在完整镜头语言规则库与正式优先级之下承担 Stage 1 创作裁决。它决定拍什么、不拍什么、镜头数量、顺序、时长与摄影机行为，不得覆盖`horizontal-shot-language-rules.md`的编号规则。它不是某部剧集的镜头模板。

## 1. 原文与本集承诺

完整阅读相关集与资产后，用一句话锁定本集兑现的主要承诺、观众主要跟随谁、压力如何转移、普通场怎样为关键场让出强度、结尾留下什么未解决问题。不得提前泄露后文或重写事件。

把每场压成一条视觉决定链：谁想从谁那里得到、阻止、隐藏或证明什么；采用什么策略；依靠什么人物、信息、物件、位置或身体条件；策略在哪里失败、改变、被识破或重新取得主动。

潜台词必须转成可见表演：靠近、退开、占据前景、控制出口、放下物件、拒绝对视、打断、换位、让对方先失控。没有改变身体、距离、道具、视线、声音或观看关系的分析，不进入镜头。

## 2. 先在横幅空间里演完整场

写镜头前先确认真正参与事件的人物、门窗、桌椅、走廊、车辆、关键道具、路径、高差和现实光源。让人物目标通过横向距离、前后层次、遮挡、空位和进入/退出画面成为可见关系。

横幅不等于把人排成一排。优先寻找：

- 同一画面中两人或三人的不对称关系；
- 前景压力、中层行动与后景后果；
- 空位、门口、窗、镜面或道具如何预留即将改变关系的位置；
- 人物走位怎样在一镜内改变权力、亲密、危险或信息归属；
- 细节怎样回到已经改变的整体关系。

人物策略、关系与观看任务未变时，允许表演在同一镜内持续。变化发生在策略、筹码、身体或道具结果、关系位置、信息所有权或情绪归属真正改变之处。

## 3. 镜头单位与切点

一镜等于一个连续摄影机任务，加一个主要戏剧节拍。同一摄影机任务可以从关系画面经过人物、身体或道具，最后落到新的关系，只要路径、时间和观看任务连续。

每镜至少完成一项工作：揭示事实、施加压力、呈现身体或道具变化、让新情绪落地。相邻镜若主体、关系、角度、尺度、动作与压力均未改变，合并或删除。

切镜只在观众需要新的观看决定时发生，例如：

- 说话策略改变，真正的接收者接管画面；
- 动作从意图进入关键接触或产生新后果；
- 道具改变对白含义或关系位置；
- 空间中的第三人真正加入事件；
- 沉默、拒绝或决定成为比台词更重要的结果。

不要按说话人、标点、动作步骤或景别配额拆镜。突然性是卖点时，不为连续性提前表演预备动作。

## 4. 整场摄影机行为

拆单镜前先决定：观众站在哪里；何处保持稳定；第一次运动由什么触发；何处收紧；何处故意不切；何处释放距离；结尾回扣哪个已建立的人物、道具或空间关系。

摄影机运动必须揭示信息、跟随动作、重新组织人物、增加压力或标记关系变化。写清起幅、触发、路径、运动中的表演变化、落幅以及落幅前后发生的台词或动作。吊臂、车拍、稳定器、手持和长焦只是执行选择，不是价值本身。

先选择观看关系，再选择景别、角度、摄影距离、焦段与景深。广角必须允许摄影机真实靠近；长焦必须确实需要压缩、隔离或远距离观察。机位高度首先保证当前身体平面和面部可读，再承担权力含义。

## 5. 对话与表演

一句对白可以连续跨过说话人、听者、关系画面和道具，不因切镜重说。把每个对白片段放进实际发生的动作、视线、接触、持物变化或停顿中，并按真实拍摄语言给足时间。

双人或三人关系、听者反应和持续表演都需要保护，但不能默认用共享构图承包整场。过肩、单人和正反打只有在关系压力、隐藏信息或观看所有权需要时使用；前景存在人物或物体时直接点名。相同景别、相同角度的机械反打不能代替场面发展。

## 6. 动作、亲密与奇观

把动作理解为`意图/危险 -> 运动或接触 -> 可见结果 -> 反应或余震`。不要求每步一镜；只有观众必须重新辨认攻击者、目标、路径、伤害、状态或社会意义时才切。

亲密场面保持剧本程度与同意关系。热度来自距离、遮挡、手、呼吸、衣料、退让、接收反应与控制变化，不把身体切成无主人的零件。每个关键关系 Beat 至少安排一个可独立读取人物变化的单人、过肩反应、近景/大近景或具有关系功能的身体/道具特写；共享双人镜头不计作替代。细节之后回到改变后的关系。

奇观、车辆、魔法与破坏必须回到被改变的人、道具、空间或决定。不得只展示规模。危险动作保留理想成片效果，同时提供最少的合成、隐藏接点或受控执行路径。

## 7. 必要覆盖

先完成成片主序列，再判断是否需要覆盖。覆盖只解决：不可重复表演、关键动作接点、AI 续接风险、复杂声音桥或剪辑无法安全退出。覆盖不能弥补平庸主序列，也不能变成大全中近套餐。

每个覆盖镜必须写明保护哪个主镜或切点、提供什么不同信息、为什么现有主序列无法可靠承担。没有具体理由就删除。

## 8. 完整导演句

每镜先形成一句自然导演说明：摄影机从何处看谁；起始身体、道具与关系是什么；什么触发人物或摄影机；动作如何改变距离和构图；对白在何时发生；最后留下什么可见结果；切在哪里。

七列只是这句话的执行展开。`摄影机`压缩成主体与景别、焦段、位置、高度角度和运动；运镜触发与落幅由`画面内容`沿同一时间线完整展开。任何一列若引入另一动作、另一时间线或不存在的切点，回到本层重新决定，不能用技术解释拼补。
