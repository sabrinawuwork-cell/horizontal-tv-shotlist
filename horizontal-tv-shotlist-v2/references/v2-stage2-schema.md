# V2 Stage 2 极简固定提示词输出 Schema

本文件保留 V1 卡片排版、frontmatter、状态和批准规则，落实 V2 的可选音色、群演分类和固定条件边界；人物受光与机位可见背景分别建模。

Stage 2 使用 Markdown 权威稿，`artifact`固定为`horizontal-tv-stage2`，每个场次独立标记状态。类别名称在当前场次内唯一，不列镜号、镜号范围或适用镜号。

```yaml
---
artifact: horizontal-tv-stage2
project: project-id
episode: E01
version: v001
status: draft
source_stage1: episode-E01-approved.md
scene: "1"
scene_image: assets/scene-1.png
stage1_sha256: <digest>
speaking_characters: 角色A, 角色B
voice_prompt_required: no
environment_required: no
extras_required: no
scene_sound_required: no
---
```

正文不用表格，固定采用“一个三级标题对应一张类别卡片”。允许的类别前缀仅为：`基础音色·`、`场次音色·`、`阶段音色·`、`光影·`、`背景·`、`环境·`、`群演外观·`、`群演动作·`、`群演光影·`、`场次声音·`。`固定视觉·`已废止并视为错误。

按[固定提示词协议](v2-stage2-fixed-prompts.md#二建立类别前的必要性测试)，先确认能正确复用，再判断实际复用需要及固定价值，不按多数票决定；必要信息不能因未建卡而省略。若整场不需要任何固定类别，正文可以没有卡片；保留完整 frontmatter，并在标题下写一段非卡片说明“本场无须建立固定类别”。该说明不会进入 Stage 3。

```markdown
### 基础音色·角色A

音色：……

### 光影·角色A

光影：逻辑主光源……，位于……，约……K；角色自身……侧形成……lux亮面，另一侧保持……lux暗部；整体……

### 光影·角色B

光影：……

### 光影·角色A与角色B

光影：……
```

基础音色默认不创建。只有当前任务或同项目同范围有效授权明确要求音色提示词，才将`voice_prompt_required`设为`yes`，并为实际说话角色建立`基础音色·角色名`。其他项目或不明来源的旧卡不构成授权；当前项目已明确授予的同范围授权继续有效。`场次音色·`和`阶段音色·`始终为可选类别。

室外场次必须执行持续环境变化检查。风、水流、云层、雾气、草叶、衣角、烟雾或其他变化覆盖多镜并影响连续性时，`environment_required`必须为`yes`并有对应环境卡；没有持续变化时写`no`，不机械建卡。

每场不强制建立光影或独立背景卡。依据 Stage 1 及其整场导演方案，为通过必要性判断的共同光源或稳定人物受光建立最少卡片，仍使用`光影·`前缀。共同光源卡保留真实光源及稳定光态，不强制写每名人物受光侧；人物受光卡写相应人物在适用镜头中的稳定受光侧和明暗关系。人物转身、走位后的变化由 Stage 3 按已批准调度逐镜表达。仅项目策略为 `numeric` 时必须有K及亮/暗lux，不要求列全身体部位或人物背后景物。

背景由当前机位在场景图中实际看见的区域决定；某个背景方向反复出现、影响空间识别且参考图无法稳定控制时，才建立独立`背景·`卡，写必要空间锚点、纵深与有依据的曝光关系，数值按项目策略。没有可见背景时不要求背景文字或数值，不为机位变化拆分人物光影。

`environment_required`、`extras_required`和`scene_sound_required`必须明确写`yes/no`。`yes`必须有对应卡片，`no`不得出现对应卡片。普通室内、无持续群演、无清楚可闻的持续声音时均写`no`。

正文机械展开前把卡片内段落换行转换为`<br>`。卡片不得包含`无配乐无字幕`、通用皮肤质感句、镜号、范围、适用镜号、待替换占位符、“同上”“保持不变”或临时负面限制。approved 稿不得存在待确认项。

卡片正文止于下一张卡或下一节标题。若需要非卡片说明，使用一级或二级标题另起说明区，不紧接在最后一张卡正文后；说明不进入模型请求。
