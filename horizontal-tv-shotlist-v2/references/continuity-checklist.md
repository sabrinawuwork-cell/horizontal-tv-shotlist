# 横屏分镜连续性检查表

连续性是硬规则层。它保护剧情事实与已经完成的导演选择；发现问题时输出`RETURN_TO_DIRECTOR`与最小冲突事实，由 Stage 1 导演阶段修订，再从受影响步骤向后复核。连续性层不得自行补镜、删镜、拆镜、改节奏或增加保险覆盖。

## 场景底图

- [ ] 门、窗、楼梯、走廊、家具、座位、出口、地标和背景布局已建立且未在反打中镜像。
- [ ] 每名人物的初始位置、朝向、站坐状态、目标位置和移动路径清楚。
- [ ] 主轴线已确定，并记录核心人物、目标物、行进或攻击关系处于轴线哪一侧。
- [ ] 长桌、会议、宴会、审判或多人场面已有座位图与局部关系轴。
- [ ] 现实光源的位置、方向、开关、遮挡和移动方式稳定。

## N 到 N+1

- [ ] 人物银幕左右位置一致；若改变，存在清楚可见的合法越轴或空间重置。
- [ ] 180°轴线成立；合法越轴通过轴上镜头、中性镜头、连续移动或人物主动跨轴完成并维持新轴线。
- [ ] 视线方向、观看对象、视线高度和距离匹配。
- [ ] 人物进出画、行进、追逐、车辆或攻击方向连续。
- [ ] 动作起势、启动、主要过程、接触/受力和结果由镜头链完整承担。
- [ ] 动作中切时，两镜处于同一动作阶段；轻微动作重叠没有让动作发生两次。
- [ ] 人物自身左右手、惯用手、受伤侧、支撑侧保持一致。
- [ ] 武器握持手、枪口/剑尖/剑柄方向、目标和轨迹一致。
- [ ] 道具持有人、所在手、朝向、开合、满空、损坏和放置状态一致。
- [ ] 门扇方向、人物所在门侧、椅子位置和坐起朝向一致。
- [ ] 伤口、血迹、服装破损、湿润/污损和身体状态按时间递进。
- [ ] 背景人物没有瞬间换位、消失或抢走主 Beat。
- [ ] 光源、受光面、反打、镜面和人物走位具有现实来源；动态光变已在画面中发生。
- [ ] 剪辑列引用的动作、目光、声音或接触确实在当前镜头发生。

## 信息、情绪与关系

- [ ] 不看作者解释也能从主序列读出本场的戏剧变化、人物策略、观众信息与感受、节奏重音和声画选择；对应方案确实落实。

- [ ] 每个关键 Beat 的必要信息与情绪都清楚；普通场景允许同一镜头同时承担，不为配额强制拆镜。
- [ ] 关键关系变化和双方不同的反应被读清；共享构图、单人、过肩或特写均由实际观看任务决定。
- [ ] 反应镜头只给真正改变剧情理解的人，群体反应只选择最有叙事价值者。
- [ ] 没有无叙事功能的运镜、特写、空镜、浅景深、荷兰角或纯风格镜头。
- [ ] 持续相同尺度或重复构图有实际观看作用；不只因三镜形式相同就要求变化。
- [ ] 场景最后一镜形成余韵、悬念或方向引导。
- [ ] 场景结束时人物最终位置让关系、信息、目标、危险或下一步行动的变化可见。

## AI 制作边界

- [ ] 每镜最多四名主动人物，例外只对`active_cast_authorizations`点名镜号生效。
- [ ] 镜头时长由表演、动作、信息读取及剪辑关系反推，没有先套默认秒数。
- [ ] `20–30s`只对`long_shot_authorizations`点名镜号生效；任何镜头不得超过`30s`。
- [ ] 每镜只有一个主要叙事功能，可有一至两个次要功能，没有竞争动作中心。
- [ ] 复杂摄影机路径具有叙事动机、明确状态节点和可重建落幅。

## 动作场景复述

动作场景完成后，按时间顺序用一句连续动作链复述：人物目标 → 准备 → 启动 → 路径/障碍 → 接触/受力 → 结果 → 余震。若无法连续复述，说明动作衔接仍有缺口，必须返回导演阶段。
