# V2 验证覆盖与方法验收

验证分别回答：确定的来源/格式/操作关系是否正确；导演方案、分镜、提示词及实际交付内容质量是否成立；真实视频中模型是否落实。前两者现在就验收，真实视频未生成不妨碍作出内容结论。明确哪些原有能力保留、哪些bug减少、需求兑现及返工变化，不能只报工程通过。

生产交付每个阶段只调用所需入口；完整任务导出已包含Stage3检查，原表更新自身检查来源和范围，不要求用户或代理额外串跑所有继承校验器。母版、兼容与结构/回归检查用于安装更新和相应维护变更。正文语义、表演与美学不增加关键词门禁。

## Stage 3 执行展开的通用验证

恢复和修改展开方法时，用相同的简写上游比较实际提交正文，保留原始版有效方法和后来解决的重复问题；不以不同导演稿的差异推断编译收益。覆盖不同观看、动作和声画关系，并包含不应展开的边界：人物/非人主体、身体与接物、说话同时/之后、听者与画外声、清晰对象不变/既定焦点变化、动作切/声桥、持续运动切出/无声停留、真实参考承担/必要条件由文字承担。换角色、场景或动作对象后同一原则仍应成立，不把样例人物、方向、数字或字段长度变成规则。

验证生成方法时，先保存未经过内容审读修补的第一份完整正文并单独评价；最终修好不能抵消首稿未完成写作。内容复核分别回答：正文中的具体演出与观看是否实现导演意图，关键过程是否仍需要接收者另作设计；执行过程、摄影与声画时机是否比简写更明确；剧情、意图、拍法与接续是否保持；原有有效的表演、观看、节奏和收束有无丢失或被无意义细节压住。静默、静物或上游已完整的镜头允许保持简洁；多写、加时码或填满类别不自动算改善。反例中的新增事件、换手、重演、反转先后、无因拉焦/停机，应由对源审读识别，不交给动作词数量检查。

结构/来源/导出回归与内容评价分别记录。单例通过只证明该例，跨类样例也不等于所有场景已验证；保留失败、限制与复核依据。真实模型执行需实际素材验证，不把文本“更明确”宣称为稳定或完美出片。

## 确定关系的自动检查

- 新生成稿明确引用导演方案；方案与分镜绑定同一剧本和场景图，文件变化使旧引用失效。`--require-plan` 不证明方案的创作先后或质量。
- Stage 1/2/3 的来源、状态和摘要一致，主镜完整、唯一且按序，时长与片段区间准确，单镜和单片段不超过30秒。
- 七列/五列、类别段落、镜号、明确摄影参数与逐字追溯列保持契约；术语含义与拍法完整性由内容复核，不以词命中认证。
- 对照明确发声定位与权威清单核对原文、数量和顺序，允许合法拆句；记录的分类与完整性、说话人及未声明发声仍须对源内容复核，不用引号猜测。
- 逐镜选定固定卡完整展开，单镜例外有真实上游依据；人物光影不强制带背景，背景根据当前取景单独选择。
- 空卡、坏行、未知来源、重复类别、默认音色残留及项目指定敏感词等按照各自明确合同判断。
- 核心母版指纹和未被授权的方法/格式文件不漂移。

`evals/v2-regression-cases.json` 中保留的 presence/ordered 旧最小示例，只证明测试文本含某些词或次序，不代表模型完成了导演任务。它们不是镜头选法的约束，也不能推翻当前导演核心。取消按早晚85mm/100mm分布判断景别质量的自动规则。

`prompt`样例的expected_valid也只表示所列格式检查结果。原R13画外人物样例保留文本、改为结构可通过：明确的画外视线对象不必被删除，画外位置是否多余、是否被错误转成入画主体仍需内容复核。运动切出同理，程序不再因缺少“最终/停稳”等词拒绝，也不凭补上这些词认证运动完整。

描述性光影同样不以“亮/暗/上方”等词面认证；均匀面板照明、阴天漫射可以正常通过Stage2/3，不要求编造阴影。光源、方向及曝光是否与本场相容由内容复核判断；显式数值模式的既有格式要求和空类别/来源保护仍有效。

## 整场方案到镜头的方法验证

使用完整原始剧本和场景素材，按正常流程先保存整场导演方案、再据此生成镜头并完成正常复核修订；不要求每次任务在方案阶段单独停止或额外交一套报告。不得预供镜数、机位答案或事后修复稿。项目级验收继续到最终提示词、任务和交付；只检Stage1时明确其范围。

情感解析在运行Schema中可选，条件类别校测不得把独立表演等同于必填；纯功能镜头仍省略。校测只检查声明的条件，不证明具体情感解释有益或合理。

检查具体决定，而不是是否写了“已重算”：

- 方案能否让整场事件在同一空间里连续发生，关键行动、接触和道具状态有没有可行路径与结果。
- 观众的视点、信息先后、必要反应和声音连接是否形成主序列，备用覆盖是否只保护真实缺口。
- 取景能否呈现它承担的动作；画外状态没有被当成画内动作，POV/焦段/机位为观看任务服务。
- 镜头是否忠实落实方案；发现问题后是否先改方案并真实传播，没有在表格完成后倒造解释。
- 更改一个起始位置、物件交接或观看决定后，真正受影响的部分是否同步，未受影响的表演与节奏是否保留。
- 同框与独立镜头、短镜与持续表演各按本场判断；不使用镜型配额、固定焦段等级或模板次序作为质量替代指标。

至少保留失败样例和未解决条件，不能只展示修过的成功稿。单个场景通过只证明该次运行，不是跨题材质量结论。真实尺度、遮挡、灯光、演员语速和视频生成需要其对应证据；格式校验、文件名、摘要和关键词均不能代替。

旧camera_format最小样例仅核对明确毫米数值；segment_boundary旧词面样例在自动自测中明确列为UNASSESSED，不计入自动通过，仍需实际任务内容审读。近景不因紧裁切本身禁止已声明可见的群演；独立反应镜型与场尾位置变化不作为内容质量的自动替代指标。
