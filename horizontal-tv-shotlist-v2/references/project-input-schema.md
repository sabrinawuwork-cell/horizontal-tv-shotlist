# 项目与单集临时输入 Schema

本文件定义每次任务需要读取的临时事实。具体值属于当前项目，不得写死进技能、题材模块或回归样本。

## 项目级输入

- 项目名、集号、版本、画幅和拍摄语言。
- 完整剧本或用户指定的权威剧本范围。
- 角色姓名、年龄、身高、惯用手、声音要求及人物参考图。
- 服装、妆容、配饰、武器、医疗器械和关键道具参考。
- 当前已知伤处、疼痛、行动限制、污损、湿润和服装破损状态。
- 是否启用战争历史背景＋医疗正剧模块。
- `voice_prompt_required: yes/no`；默认`no`。
- 受保护对白及当前敏感词授权；统一记录为`dialogue_sensitive_authorizations`，例如对白中的“红军”是否保留，无授权写`none`。
- 用户批准的敏感词替代表达；未提供时不得自行建立永久映射。

## 场次级输入

- 场次号、场景图及必要的不同方向补图。
- 门窗、通道、床位、桌椅、出口、地标和危险来源。
- 人物初始站位、朝向、距离、高低、目标位置和移动路线。
- 主轴线、局部轴线、运动方向、攻击方向和允许的越轴设计。
- 主光源位置、色温依据、遮挡关系及煤油灯、篝火、窗户等实际位置。
- 当前 near-side/far-side 连续阶段；只作为内部空间与光影推导，不直接写进 Stage 2 或 Stage 3 提示词。
- 当前道具持有人、左右手、朝向、开合、满空和损坏状态。
- 当前伤势、服装、群演分区、持续环境与场次声音。
- 镜号级长镜、主动人物或其他例外授权。

## 缺失信息处理

参考图或空间事实足以可靠判断时可以推导，并把推导写进待确认项。若机位背景、光源、人物动线、肩侧、伤处或道具方向存在两个以上同样合理的答案，先询问，不把推测晋升为 approved。

项目名、集号、Stage 1/2权威来源或其他 Stage 3 frontmatter 必填值缺失时，必须阻塞并询问；不得写“本次项目”“所属集”“待定”或说明性占位符后标记 approved。

单项目配置不进入`references/`、`examples/`、`evals/`或安装包。回归案例只保留匿名化失败模式和最小合成素材。
