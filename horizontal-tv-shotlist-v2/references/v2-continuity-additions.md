# V2 连续性与交付新增 Checklist

本文件用于对照已保存的整场导演方案和实际分镜，补充[连续性检查表](continuity-checklist.md)。检查必须指向具体产物和决定，不以写出检查词作为通过证据。

发现问题时返回对应阶段最小修订。连续性层不得自行补镜、删镜、拆镜或改变节奏。

## 剧本与主剪辑

- [ ] 整场的戏剧作用、人物策略与观众体验、视觉/声画方式、节奏重音和收束在镜头中实际成立；不是只有空间记录或一串情绪标签。

- [ ] 原文对白、内心旁白、动作、停顿、反应、道具和事件顺序无遗漏。
- [ ] 用户修改已传播到受影响的站位、轴线、视线、动作和光影。
- [ ] 每个切点来自信息、情绪、动作阶段、关系或观看任务变化。
- [ ] 必要反应属于主序列；备用反应已与主剪辑明确分开。
- [ ] 景别、距离和焦段服务当前观看任务，没有按毫米数或逐 Beat 镜型配额机械配镜。
- [ ] 每镜时长由台词、动作、反应和沉默反推，没有先套默认时长再压缩内容。
- [ ] 唱歌、长台词和持续表演已根据实际语速、停顿、反应与动作计算时长。
- [ ] 长演讲保留说话者发展与必要主序列反应；只在确有替代或接续需要时提供备用覆盖。

## 空间、轴线与视线

- [ ] 门窗、家具、床位、入口、出口、路线、危险来源和光源位置稳定。
- [ ] 人物左右、前后、高低、朝向、距离和最终位置可追踪。
- [ ] 主轴线和当前局部轴线成立；越轴过程可读，之后维持新轴线。
- [ ] 相邻机位满足30度规则，或存在明确的稳定/压迫设计。
- [ ] OTS主反打肩侧成对正确；前景位于正确画面侧。
- [ ] 人物换位后重新检查肩侧、画面左右、视线和光源方向。
- [ ] 成人与明显较矮角色的俯仰角和视线高度符合项目身高差。
- [ ] 进出画、行进、撤离、追逐和攻击方向连续。
- [ ] 场次首镜建立时间/氛围、人物/群体状态、出入口/危险方向和核心光源，或存在明确悬念/主观/延迟揭示动机。
- [ ] 观众获取信息的顺序符合设定，没有用过早客观特写无意泄露。
- [ ] 导演方案在拆镜前形成；其中位置、朝向、动作、观看和连接决定实际驱动当前镜头，复核记录没有事后倒造依据。
- [ ] 人物起身、坐下、进出、换位、绕行或进入新灯区后，已重算机位、肩侧、画面左右、视线和光影。

## 动作、道具与身体

- [ ] 关键动作包含准备、启动、过程、接触/受力、结果和必要余震。
- [ ] 动作中切处于同一动作阶段，同一动作没有在相邻镜头重做。
- [ ] 左右手、抓握点、端持方式、武器/器械方向和道具状态一致。
- [ ] 伤处、疼痛、行动限制、服装破损、污损和湿润状态递进。
- [ ] 医疗或技术操作呈现困难、判断、实施与结果，没有只给结果。
- [ ] 群演没有瞬间换位、同步机械反应、遮挡主体或冲撞路线。

## 摄影机与光影

- [ ] 每镜是连贯的观看事件，运镜有叙事原因，并明确切出构图和运动状态；设计要求停稳时，明确停止节点。不因包含多个连续Beat而机械拆镜。
- [ ] 摄影机描述与画面内容属于同一时间线。
- [ ] 具体毫米焦段、景别、相对机位、高度、角度和运动齐全。
- [ ] 光源位置、人物自身受光与当前可见范围一致，数值仅在项目要求或已采用时核对依据；依赖机位的背景没有被当作人物固定属性。
- [ ] Stage 2/3没有用 far-side/near-side 元术语代替物理结果。
- [ ] 煤油灯固定结尾只用于煤油灯真实持续主导的类别。
- [ ] 复杂调度的主要观看任务、起幅、触发、人物路线、摄影机路径及切出构图相互成立；切出可以仍在运动，只在设计包含停稳时检查其节点，不为清单补停顿。
- [ ] 高风险复杂镜头已在内部标记测试与自然拆分点，没有因 AI 风险自动简化。

## Stage 2

- [ ] 只建立跨多个镜头稳定复用且容易漂移的类别。
- [ ] 音色仅在用户或项目配置要求时建立。
- [ ] 光影按真实光态、轴线和站位结果拆分，不按景别或机位名称拆分。
- [ ] 群演外观、动作和光影没有合成超长复合卡。
- [ ] 单镜例外、瞬时声音和普通室内理论底噪没有进入固定类别。
- [ ] 所有卡片可原文展开，approved 中没有待确认项。
- [ ] 室外场次已检查持续风、水流、云雾、草叶、衣角和烟雾等是否需要环境卡。
- [ ] 人物换位、摄影机换侧或轴线改变后，人物—机位—光源映射已重算。

## Stage 3

- [ ] Stage 1与Stage 2均为approved，生成前阻塞清零。
- [ ] 每个Stage 1镜头完整落入一个不超过30秒的片段。
- [ ] 实际任务首镜自足；显式复用计划的任务内部连续性与成片插入后的连接分别成立。
- [ ] 五列准确；只有实际问题才增加备注列，红色阻塞不放行，现有黄色情感备注行为不变。
- [ ] 分镜内容逐字合并摄影机、画面内容和音效，不含剪辑衔接。
- [ ] 每镜以所属任务的素材时间开头；显式计划的回用行不按上一成片行重置，焦段、景别和主体不重复。
- [ ] 画面只写起幅，动作/表情写过程、运镜触发和落幅。
- [ ] 情感解析独立且有剧本依据，不新增事实或动机。
- [ ] 固定卡直接展开为自然类别，没有`固定类别`标签或占位符。
- [ ] 群演动作符合当前剧情阶段，错峰且不遮挡主体。
- [ ] 参考图艾特准确、完整、不过量。
- [ ] 画外角色不被新增为入画主体；按已批准分镜保留必要的视线目标、受话人或声源姓名及方位，不添加其不可见外观、动作或完整站位。
- [ ] frontmatter使用真实项目、集号和权威来源，没有说明性占位符。
- [ ] 可见皮肤时加入规定皮肤质感句，不可见时不机械添加。
- [ ] 每个类别之间真正换行并空一行。
- [ ] 没有重复、绕口、病句、错字或类别堆叠。
- [ ] 敏感词预检通过，受保护对白具有当前授权。
- [ ] 每个独立生成任务开头为`全片要求：不添加背景配乐，不生成字幕。`，结尾保留`无配乐无字幕`；不强制任务内逐镜重复，五列表格式不变。
- [ ] Stage 1台词已逐句比对，除当前明确授权的平台安全处理外无删减、概括、改写或缩短。
- [ ] 独立人物表演镜头已判断情感解析必要性；纯空镜、道具、环境和功能镜头没有机械添加。
- [ ] 根据真实裁切和叙事需要判断群演是否可见/必要，没有用焦段数值直接决定是否添加。
- [ ] 声音只保留真实环境声、物理声和必要画外声，没有重复动作/表情中的对白、哭声或笑声。
- [ ] 片段首镜给出该故事时刻需要的自足可见初态，没有用“继续上一片段”等代替实际事实。
- [ ] 片段末镜留下后续需要的实际结果；画外持续状态保留在导演方案中，不强塞进当前画幅。
- [ ] 片段内必要切镜和声音桥已落实，跨片段后期组接依据仍可追溯；没有丢弃导演连接意图。
- [ ] 默认输出中不存在`【角色名音色参考：】`或任何同类块；仅当用户在当前任务明确启用音色时例外。
