# 横屏剧集场景模板

本文件为执行用途整理权威规则库中的`SC01–SC12`。原文与编号的权威版本位于[横屏镜头语言规则库](horizontal-shot-language-rules.md)；以下公式是镜头设计顺序，不是固定镜数，必须按场景长度、表演与空间删减或组合。

## SC01 普通对白场景

**空间建立 → 共享关系或明确视点 → 根据话语权与受影响者切换单人 → 关键反应 → 关系结果。**关系稳定且双方距离需要同时读取时可以同框；出现隐瞒、冲突、心理分离或听者理解变化后，及时进入过肩、单人和反应镜头。关键台词根据“谁发生变化”决定落点。

## SC02 争吵、谈判与权力对抗

**原始权力构图 → 语言试探 → 距离或高度变化 → 景别收紧 → 权力反转或关系破裂。**通过中央、出口、主位、高度、起身、逼近、绕桌、挡路或前景改变权力，不以音量和快切代替调度。

## SC03 爱情、暧昧与亲密场景

**共享空间 → 单人视线与反应建立 → 距离逐级缩短 → 私人空间被突破 → 身体/道具细节确认许可或犹豫 → 接触 → 分别读取双方反应 → 关系确认。**双人镜头建立距离变化和接触结果；单人、过肩、反应近景与必要特写负责表达双方不同步的欲望、试探、许可、退让和拒绝。每个关键关系 Beat 至少有一个上述独立可读镜头，共享双人/多人镜头不能替代；不设置固定比例。

## SC04 悬疑与潜在危险场景

**建立正常秩序 → 放入异常但不立即解释 → 控制谁先发现 → 延迟确认 → 危险进入同一空间。**用深景深、遮挡、长焦、画外声和背景动作控制信息差，不靠黑暗、慢推和空镜拖延。

## SC05 调查、发现与证据场景

**角色目标 → 搜索路径 → 错误或次要线索 → 关键细节 → 识别信息 → 决定下一步。**证据先可识别，再给人物理解，最后明确如何改变行动。

## SC06 真相揭露与反转场景

**维持错误认知 → 植入矛盾信息 → 关键证据或行动出现 → 受影响者反应 → 重新建立全场关系。**揭露后通过双人、多人或拉远确认谁失位、谁掌控、谁重新站队。

## SC07 打斗与近身动作场景

**空间和双方目标 → 动作起势 → 中景展示主要技术和身体关系 → 特写强化关键冲击 → 全景或中全景确认结果。**每轮明确发起者、目标、方向和结果；清楚优先于速度。

## SC08 追逐与逃亡场景

**逃跑原因 → 总体运动方向 → 追赶距离 → 障碍改变路径 → 距离缩短或拉开 → 追逐阶段结果。**用地标、门口、走廊、街道和转弯维持地理方向，每次切换都更新危险程度。

## SC09 恐怖与惊吓场景

**建立空间安全规则 → 放入异常声音或细节 → 角色调查或否认 → 视线受限 → 危险出现或规则被打破 → 后果。**惊吓必须建立位置与时间准备，持续恐怖依靠等待、背景和画外空间。

## SC10 喜剧场景

**建立正常预期 → 信息错位或行为升级 → 保持镜头让尴尬发展 → 在最佳时点切到反应或结果。**固定双人或多人镜头优先保护原因与反应同框；风格化手段必须服务明确笑点。

## SC11 群戏、会议、宴会与审判场景

**建立座位与阵营 → 明确发言中心 → 通过视线和 Blocking 转移话语权 → 关键人物打破秩序 → 全场关系重新排列。**先制作空间图和座位图，优先多人构图、代表性反应和前后景关系；每镜默认最多四名主动人物。

## SC12 蒙太奇、时间压缩与过渡场景

**明确蒙太奇目标 → 选择具有递进关系的动作或信息 → 使用动作、构图、声音或概念匹配连接 → 以明确结果结束。**每镜推动时间、能力、关系、调查或计划，顺序必须形成开始、发展和结果。
