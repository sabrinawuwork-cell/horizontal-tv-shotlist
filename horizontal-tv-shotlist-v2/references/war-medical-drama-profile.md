# 战争历史背景＋医疗正剧题材模块

本模块只在战争历史背景、前线/后方医疗、伤员救治、撤离、历史低照度或相近题材中加载。它提供可迁移方法，不包含任何项目角色名、场次位置或专属道具状态。

## 群戏空间组织

- 先把空间分为医疗操作核心区、病床/伤员区、物资区、过道与撤离路线、主要人物后景和远景危险方向。
- 每个镜头只设一个主要行动中心。医护操作、伤员反应、战士行动和背景群体不能同等清晰、同时抢戏。
- 用前中后景呈现压力：前景可承担器械或急迫动作，中景承担主要救治/关系，后景承担等待、戒备或危险后果。
- 群演动作错峰发生。近处人物可先反应，远处人物随后转头、停手、让路或继续任务，不让全体同步。
- 突发声音、攻击或撤离命令前后必须建立不同群体状态，不能复用同一套背景动作。

## 伤员与医护调度

- 每名伤员的伤处、支撑侧、行动能力、疼痛反应和所需协助写入项目配置并持续追踪。
- 医护人员的操作位置、器械手、递交方向和身体遮挡保持稳定；不要为了反打镜像器械或换手。
- 搀扶、抬运和转移写清谁先支撑、支撑身体哪里、伤员重心向哪侧、谁控制路线和最后落位。
- 医疗操作镜头优先让观众理解困难、判断、实施和结果。不能只给器械特写后跳到病情改变。
- 技术操作保持克制、准确和可读；不靠大量快速特写伪造专业感。

## 医疗操作镜头

按`观察症状 → 判断问题 → 准备器械/药物 → 操作 → 身体反馈 → 结果确认`组织。并非每步都要独立成镜，但必要因果不能缺失。

明确左右手、器械尖端/开口/刻度方向、接触部位、操作路径、伤员姿势和医护视线。涉及体液或痕迹时先执行平台安全语言，不改变医疗事实。

## 撤离与危险节奏

- 先建立危险来源、出口、撤离路线、伤员速度限制和可用人手。
- 节奏来自任务变化和距离变化，不等于大量短镜头。
- 清楚保留命令被听见、人员反应、物资取舍、伤员移动、路线受阻和阶段结果。
- 危险段落可加快剪辑，但起势、关键接触和结果必须可读。撤离结束后给出人员、空间或任务状态的可见结论。

## 历史环境与光源

- 光源必须来自场景真实存在的煤油灯、篝火、窗光、月光、车辆灯或其他项目确认来源。
- 历史低照度正剧优先保持低照度、高反差、暗部可读和背景低于人物，不给人物增加无来源聚光。
- 煤油灯或篝火的动态应轻微、不规则，并明确作用方向与区域；避免让整场亮度同时无规律跳动。
- 只有煤油灯持续承担主要光源时才使用固定结尾：`煤油灯轻微、不规则地跳动，整体低照度、高反差，真实电影质感。`

## 克制表演与群体反应

- 正剧表演优先通过停手、让路、压住疼痛、重新握紧器械、低声下令、短暂对视或继续任务表达，不机械堆积眼泪和夸张震惊。
- 长演讲或集体决定要检查直接承受者、医护、伤员和必要群体的不同反应；主序列保留改变理解的反应，其他放入备用覆盖。
- 群体反应体现身份差异：正在操作的人可能只停半拍，伤员可能抬眼，警戒者可能转向危险方向，指挥者可能先观察路线。
