# 最初V2与当前本机版：完整双场对照

## 结论

本次更推荐当前本机版。最终提示词的制作条件传递与可执行交接有明确改善；导演分镜在这场戏中更连贯，主代理在关系表演组织上小幅偏向当前版，但不称艺术表现全面胜过原始版。当前最终稿未发现本轮可坐实的未解决重要问题；原始版终稿仍有一处机位侧别矛盾和一组布景条件传递遗漏。

稳定性不能宣称已得到重复验证。两名clean sub-agent各用一个版本做一次完整流程；两版均有自修，当前版没有证明首稿更稳、返工更少或更快。此次只支持当前终稿与交接更可靠的有限证据，不是同版多次运行的成功率，也不是视频生成效果。

## 对照条件

用户要求两个clean sub-agent对比最原始版与当前本机多轮优化版。最初V2沿项目现有基线8c1125671f2d07d1e1c529838dd01f5e9e8dd4b5，当前版冻结本机HEAD 73f1e3b及未提交Stage3改动。两位均Astra/medium、fork_turns=none，只收到各自运行目录与相同制作任务；不读历史产物、评审、另一版或本轮主持对比表，不能修改冻结技能。主代理未给创作修法或中途内容提示。两版均获得相同离线模拟批准、自查修订、通用工作簿资源和必要交接文件制作权限。

使用新编匿名完整双场《先别封》及两张已有木屋参考图，文字输入明确布局、角色、手物条件和无需独立人物/道具图。没有重做旧样例，也没有让旧版因已知缺参考条件而注定无法完成。相同用户条件允许自然描述光影；如本版必须数值化，可明确作为设计目标。冻结输入与两份技能共195文件，终验摘要未变。该目录隔离是任务指令隔离，不宣称操作系统访问权限隔离。

两名制作代理完成后，由主代理对原始剧本、制作条件、最终分镜/提示词/任务/请求、工作簿及真实自修记录作比较。主代理知道版本身份，不能称独立盲评。原始版两个残留疑点另经制作代理只读确认，确认发生在48份最终文件冻结之后，未获得修稿机会。

## 分镜的具体比较

两版均保留封盒被打断、小周提出等候后被遣离、钥匙留下、照片不向观众展示、短笑收住、两只手先后接近盒盖、梁青先收手后才说“明天再封”的完整关系过程。护具侧右手没有承担操作，何伯没有取钥匙，小周未在第二场重新出现；没有补照片内容或离开原因。

当前1B把何伯左手按盒沿与梁青持盖停住放在同一双人镜内，阻止与接收同时可读。当前2D把左手伸停、空右手落盖、对视、梁青收手连续放在共享画面里，最后2E让话语与点头共同收束。观看的优势是较少打断两人的即时关系，又保留2B对梁青“现在也不大”的独立接收视点，并非一律不用近景。

原始版1C/1D分开强调何伯的拒绝与梁青的停手，2E手部特写让谁先接触盒盖更醒目，2G把何伯画外对白落在梁青近景，随后2H再给5秒空间余韵。这是有效的导演方案，局部细节与停留比当前更突出，不能把分切本身判成错误。主代理对这场克制关系戏小幅偏向当前连贯的同框组织；没有证据外推为所有题材艺术水平都提高。

原始1E存在确定的表达矛盾：场次说明的小周机位(1.0,1.0)相对门内朝西北的小周处于左前侧，摄影机列却写右前方，提示词原样继承。无需假设人体尺寸或镜头成像即可确认左右标签与自身坐标不一致。制作代理已确认，见[只读裁定](baseline-author-clarification.md)。当前以实际固定场景机位与方向表达，未见该处对应矛盾。

## 提示词的具体比较

当前四个任务均在正文提供6×4米布景、门窗/桌床位置、桌高、角色及必要道具定义、实际初态，并注明参考图只承担材质、场景说明不等于全部入画。任务2—4的站位朝向曾在首稿不足，自查后回主稿补齐，再同步原生任务和请求。最后机位修订也完整传递到工作簿与request。用新场景实际验证了本轮规则的条件承接与派生维护，未仅凭旧六镜修补例宣布成功。

原始版同样保持对白、动作顺序、手物与照片保护，也能通过额外脚本交齐任务，不是完全不能做Stage3。其任务只写北窗、南门、东床、桌北坐位等定性关系，未传入制作条件指定的室内尺寸与门窗/家具几何布局。参考用途又限定为材质，不能靠所附图弥补这一组已决定信息。该判断不是要求每个数字都照抄，而是请求明确称布局以文字为准，却没有向模型传入本次指定布局；与独立请求可执行性直接相关。

当前共同光源卡在每任务只出现一次，原始版重复展开人物/组合数值光卡；当前省略不必要的情感解析而仍保留可见表演。减少重复是可观察收益，但情感解析有无、光影是否数值化本身不算好坏，须看是否保留意图。当前任务首镜仍较长，主要增加实际制作条件；不能仅凭短了或长了宣称模型执行更好。跨任务身份和真实成像未测。

## 稳定性和返修

原始版：首稿时长汇总多4秒；自查缩近梁青与盒盖的触达距离；回上游降低并调整全景机位，再同步下游。工作簿另修原生导出说明中残留draft文案和显示余量。最终仍漏查上述侧别与布景传递问题。

当前版：首稿元数据/场次说明格式造成9条连带解析报错，实质是几项格式填写问题，不算9个创作错误；自查补独立任务朝向；删第二场说明中误复制的小周内容；回方案调整共享镜朝向和末镜焦段，并同步全链。另修依赖链接路径、核对脚本namespace及工作簿展示。依赖/辅助脚本错误与导演/编译问题分开记录。

双方都完成了不依赖主持修法的正常自查与修订，但当前也经过多次修改。不能据原始残留2组、当前未发现残留就推算跨任务零错率。原始报告的约10分钟从Stage1首稿计起，当前约14分钟从导演方案计起，前置阅读均未完整计入，两个起点不同，不进行速度倍数或总体效率比较。

因此：本次最终分镜组织偏向当前，最终提示词交接明确偏向当前；本次最终残留错误更少，但重复运行稳定性改善尚未证明。保留当前采用判断，不为了本轮排名继续修改技能或冻结产物。
