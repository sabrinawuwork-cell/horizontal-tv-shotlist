# 匿名横屏正剧前向测试源剧本

## 场次 1｜室内·社区听证室·傍晚

公开说明会结束后，四名居民留在北墙长椅附近。角色甲坐在长桌西端整理蓝色档案夹，角色乙坐在长桌东端，右脚压住一张折叠纸页的边缘。角色丙站在长桌北侧的记录台旁。

角色甲抬头问：“原件在哪里？”

角色乙没有回答。角色甲翻完蓝色档案夹，里面只有空的透明文件套。她停下来，看向角色乙，再说：“我问的是签过字的原件。”

角色甲低头时，发现角色乙右鞋旁露出一角折叠纸页。纸页翻起的边缘露出正式印章和被撕断的日期。角色甲看回角色乙，说：“把脚移开。”

角色乙把右脚移开。角色甲起身，绕过长桌北端，弯腰捡起纸页，继续走到北墙公告板前。角色乙留在座位上转身面对她；角色丙从记录台后转向两人。角色甲展开纸页，说：“这张纸不是一个人的疏忽。它说明我们每个人都看见了缺口，却都希望下一个人先开口。”

居民们逐渐停止收拾，朝角色甲看去。角色甲继续说：“如果今晚再把它放回抽屉，明天就会有人替我们承担后果。”

角色甲把纸页举到胸前，说：“所以我会把它交出去，也会在记录上写下我们三个人的名字。”

角色乙起身，说：“先写我的。”

角色丙拿着登记簿走到公告板前。角色甲把纸页放到登记簿上，角色乙走到她身侧。四名居民保持距离看着三人。
